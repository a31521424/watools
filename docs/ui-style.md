# UI 风格说明

[返回文档索引](./README.md) · [返回仓库速览](../AGENT.md)

## 界面定位

WaTools 的主界面不是传统多页面应用，而是一个桌面级 command palette。

当前 UI 设计重点是：

- 快速唤起
- 低干扰
- 键盘优先
- 面板式工作流
- 插件作为能力扩展，而不是独立导航站点

## 界面结构

主界面壳在 [`frontend/src/components/watools/watools.tsx`](../frontend/src/components/watools/watools.tsx)，当前路由分为：

- `/`
  主命令面板
- `/plugin`
  UI 插件 iframe 容器
- `/plugin-management`
  插件管理页
- `/log-management`
  日志管理页
- `/update-management`
  更新管理页

其中插件页、插件管理页、日志页和更新页会进入固定高度面板模式，和主命令面板的动态高度逻辑区分开。

## 视觉基调

从当前样式实现看，界面基调是轻量、克制、偏系统工具风格：

- 透明窗口背景，突出悬浮感
- 白色主容器作为实际内容承载层
- 大圆角面板，搭配轻边框与阴影
- 文本与控件偏高密度，服务快速输入与检索
- 默认隐藏滚动条，减少视觉噪音

相关样式主要分布在：

- [`frontend/src/app.css`](../frontend/src/app.css)
- [`frontend/src/style.css`](../frontend/src/style.css)

## 设计令牌与组件风格

当前前端采用 Tailwind 4 的 theme 变量方式组织基础令牌，定义了：

- 颜色变量
- 圆角变量
- 边框与输入态变量
- 图表与 sidebar 变量

虽然存在 `.dark` 变量集，但当前主要交互界面仍以浅色工具面板体验为主，不应把项目误读成完整的深浅主题系统。

基础组件风格来源于：

- `cmdk` 提供命令式列表交互
- `radix-ui` / shadcn 风格基础封装
- Tailwind 原子类完成最终组合

## 交互风格

主界面的交互约定非常明确：

- 全局热键唤起窗口
- 输入框默认获得焦点
- 结果列表围绕当前输入实时更新
- `Esc` 优先返回上层或隐藏窗口
- 失焦时在生产模式下自动隐藏
- 粘贴文本、图片、文件会进入统一输入上下文

这套交互说明了 UI 的真正中心不是导航，而是“输入上下文 + 匹配结果 + 触发动作”。

## 主面板与插件面的差异

### 主命令面板

- 以单输入框驱动
- 同时混合应用、操作命令、内置功能和插件结果
- 强依赖排序与历史权重
- 键盘优先，列表选择是主交互

### UI 插件页

- 通过 iframe 承载
- 不直接复用主命令列表布局
- 更像一个嵌入式工具工作区
- 上下文由宿主注入，而不是由页面自行拉取

## UI 文档使用建议

在做前端改动时，优先确认以下几点：

- 当前改动属于主命令面板，还是属于插件工作区
- 是否破坏了透明悬浮窗口与命令面板的轻量定位
- 是否仍然保持键盘优先和低噪音视觉风格
- 是否与现有固定高度管理页模式一致
