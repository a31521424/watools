# UI 风格与工作区规范

[返回文档索引](../README.md) · [返回仓库速览](../../AGENT.md)

## 当前视觉体系

WaTools 使用浅色桌面工具风格：中性浅灰背景、白色工作面、石墨色文字和蓝色操作重点。启动器、本地管理中心、插件列表、日志及五个官方 UI 插件共享颜色、字体、控件、聚焦态、间距和通知样式。

唯一基础设计源为 [`frontend/public/watools-ui.css`](../../frontend/public/watools-ui.css)。宿主通过 `style.css` 引入并映射为 Tailwind 语义变量；官方插件通过相对样式链接使用它。`pluginctl package` 将同一份样式写入每个 UI 插件包，已安装的 revision 自带样式，不依赖宿主运行时注入。只改变本体不会替换已安装的旧插件。

| 项目 | 当前规则 |
| --- | --- |
| 背景／工作面 | `--wt-bg` / `--wt-surface` / `--wt-soft` |
| 文字／辅助文字 | `--wt-text` / `--wt-muted` |
| 操作重点／淡色选中面 | `--wt-accent` / `--wt-accent-soft` |
| 分隔线／状态 | `--wt-border` / `--wt-danger` / `--wt-success` |
| 字体 | 系统 SF、PingFang、Segoe UI；代码使用 SF Mono、Consolas |
| 圆角 | 控件 7–9px，工作面 10–12px，主窗口壳 14px |
| 间距 | 工作区默认 20px，窄窗 14px；双栏间距 20–24px |
| 状态与交互 | 主操作实心蓝，次操作边框，辅助操作淡色／文字；可见键盘焦点与细滚动条 |

基础插件选择器使用 `:where()` 降低优先级，让工具自己的布局和响应式规则正常覆盖默认值。插件保留旧 `--bg`、`--surface`、`--line` 等别名。当前采用浅色主题；保留的 `.dark` 变量不代表完整的系统主题切换已经实现。

## 应用绘制的统一标题栏

[`WaWorkspaceHeader`](../../frontend/src/components/watools/wa-workspace-header.tsx) 是插件展开页、管理中心和日志页共用的应用组件，高度 72px。它展示：

- 返回启动器操作；Esc 返回，输入法组合过程交给输入法。
- 工具图标、工具／页面名称、WaTools 品牌标识和一行功能简介。长简介省略，悬停显示完整文本。
- 页面操作。插件页显示“独立窗口”和 ⌘D；日志页显示筛选、刷新和目录入口。

标题栏空白区可拖动主窗口，按钮和操作区排除拖动。它不读取或解析输入原文；简介来自插件元数据，不暴露剪贴板内容。窄窗隐藏品牌标识及快捷键标签，保留名称和实际操作。

这条标题栏由应用绘制，适用于主窗口展开的工作区。独立插件窗使用 macOS 原生标题栏、关闭／最小化／缩放按钮，不再重复渲染宿主标题栏。独立窗初始 960×760，最小 480×320，可自由缩放；插件按 iframe 的实际可用空间调整布局。

## 页面布局

| 页面 | 布局 |
| --- | --- |
| 启动器 `/` | 64px 搜索输入区、图标与两级文字结果、快捷键页脚；结果区动态高度 |
| 插件 `/plugin` | 统一标题栏、插件工具栏、主要编辑区、紧凑状态栏 |
| 管理 `/management` | 标题栏与分类切换；源码设置和更新操作分区，插件分类内提供官方安装及已安装列表 |
| 日志 `/log-management` | 标题栏、搜索和筛选、事件表格、详情侧栏；表格允许横向滚动 |
| 兼容管理路由 | `/plugin-management` 打开插件分类；`/update-management` 打开应用与更新分类 |

主窗口工作区固定高度 760px，与启动器的动态高度分开。底层窗口没有原生尺寸的浏览器预览中，不发起宽度为零的窗口缩放。

## 官方插件

五个 UI 插件从 0.3.0 使用共享设计源，功能脚本、上下文和会话接口继续保留：

- JSON：贴边编辑器、转换工具栏、按需显示的路径抽屉和底部状态。窄窗工具栏换行。
- 二维码：文本与图片双栏；窄窗改为可滚动的上下布局，保持输入和预览可操作。
- 翻译：原文与译文双栏，密钥配置按需展开；窄窗上下排列。未配置密钥时提示设置，不发起真实翻译。
- 文本统计：输入区与统计总览，细分指标可滚动；窄窗按顺序呈现输入与统计。
- 计算器：突出表达式、历史列表及简短快捷键提示，避免暴露内部存储实现。

常用工具插件只有 executable 入口，不存在需要重画的网页；系统文件对话框仍由原生能力提供。历史 `fronted-plugin/` 不属于当前加载或打包入口。

## 交互边界

- 全局快捷键唤出启动器，输入默认聚焦；应用、操作和插件结果围绕输入匹配。
- 超过 2000 UTF-16 单元的文本以首尾摘要显示，提供“复制原文”；查询不编辑摘要。插件仍使用轻量匹配，展开后接收完整上下文。
- Command+D 或“独立窗口”先捕获当前编辑状态，确认新窗恢复成功后隐藏主窗并返回 64px 启动器；失败保留原页面。支持同插件多实例。
- 唤出主窗不把其他插件窗同时置前。独立窗 Esc 关闭自身。
- 弹层、抽屉和通知限制在 iframe 内；不得另造一层模拟窗口标题栏。仅桌面宿主负责窗口外观与分离操作。
- 滚动条保持可发现，键盘焦点可见；减少动态效果偏好关闭非必要过渡。

新增官方 UI 页面应复用这些规则，将差异限制在工具的工作布局。实际实现位置见 [`app.css`](../../frontend/src/app.css)、[`style.css`](../../frontend/src/style.css) 和 [插件 UI 指南](../plugin-development/05-ui-and-shortcuts.md)。
