# 开发者自用阶段需求

[返回文档系统](../README.md) · [实施 Backlog](../backlog/README.md) · [Agent 约束](../../AGENT.md)

更新日期：2026-10-03。用户明确要求优先覆盖开发者自用，Windows 等兼容任务延期。当前主工作环境是 macOS，本阶段围绕本机可用、插件小窗和开发调试推进。本文描述目标与阶段边界，不代表功能已经实现；当前仍使用 Wails v2。

## 产品与使用场景

WaTools 是开发者常驻使用的桌面效率工具。核心路径是快捷键呼出启动器，搜索应用或本地插件，执行操作或进入插件工作区；需要持续工作的插件可以打开独立小窗，启动器隐藏后继续使用。

插件先面向开发者自己维护的官方或可信本地插件。当前需求是稳定地使用、修改、加载和调试这些工具，开放插件市场或运行任意不可信插件不纳入本阶段。

## 优先级与平台边界

- P0：当前 macOS 架构本机构建、原有功能迁移、真实插件小窗、基础调试与自用验收。
- P1：插件按需加载、开发重载、SDK 简化、诊断和 agent 工具，以及可信插件的调用与数据边界整理。
- P2 deferred：Windows 兼容和实机测试、Windows CI 与安装器、macOS universal/Intel 分发覆盖、签名公证及真实自更新故障演练。
- Linux、移动端、插件市场和完整第三方代码隔离不纳入本阶段；有明确使用需求后再评估。

延期不删除现有平台代码、CI 或历史证据，也不宣称已兼容。平台问题单独记录，不将 Windows 或对外分发验收作为本机自用阶段的完成条件。

## 开发与数据要求

- 保留 Go + React + TypeScript、SQLite 与 `.wt`，先固定并迁移 Wails v3，不同时更换全部技术栈。
- 自用可以通过本机构建与手动安装更新，操作前保留旧应用与数据；不需要先建立完整公开分发流程。
- 数据迁移、更新失败与安装失败等破坏性场景只在独立测试安装中验证。
- macOS 不恢复系统 Keychain，本地凭据为明文文件；Windows DPAPI 的实机验证延期。Secret API 名称不意味着跨平台加密。
- 性能先记录当前基线，再比较真实体验，不以框架宣传数值作为目标。

## 自用阶段完成标准

当前开发机可以稳定运行新宿主；一至两个真实插件可独立开窗并持续工作；上下文、存储和清理行为正确；开发者和 agent 能用文档中的入口启动、检查与定位错误。通过 [自用验收清单](../backlog/native-self-use-acceptance.md) 后，记录版本、架构、提交和验证证据。

P1 增强按独立项目验收。自用阶段完成不代表 Windows、公开分发或不可信插件隔离已完成，延期项目保持独立状态。
