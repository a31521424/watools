# 对外分发与自更新验收

[返回 Backlog](./README.md) · [自用需求](../requirements/developer-self-use.md)

状态：deferred。优先级：P2。延期原因：本阶段通过当前 macOS 架构本机构建与手动安装覆盖自用。恢复条件：用户明确要求对外发布、跨架构分发或真实自动升级，并具备相应签名及测试环境。

## 延期范围

- macOS universal/Intel 发布构建、目标系统覆盖、签名、公证与 Gatekeeper 行为。
- Windows 安装器、签名和发布环境，与 [Windows 验收](./windows-compatibility.md) 配合。
- 发布流水线的实际运行、版本校验、产物与更新 manifest 一致性；远端发布按明确授权执行。
- 在独立测试安装进行真实更新：下载、校验、退出、替换、重启、成功后的数据读取。
- 故障恢复：校验失败、包损坏、权限不足、替换或启动失败时保留旧应用并提供可操作提示。
- 官方插件修复包的发布与已安装版本更新说明；本机重新打包安装已由 [自用验收](./native-self-use-acceptance.md) 覆盖。

## 本阶段保留要求

不绕过当前更新完整性和数据保护检查。本机手动更新有旧包与数据备份，不能因签名或分发延期而通过真实自用安装做破坏性故障演练。当前源码的更新修复及测试继续保留，但不将它们当作真实更新流程已经通过。

## 恢复后的验收

目标平台产物、版本、签名与 manifest 可核对；独立测试安装的成功和失败路径均有证据；更新后插件配置、存储与原数据可用。未覆盖的平台和权限条件单独列出，必要时保留明确的手动安装路径。
