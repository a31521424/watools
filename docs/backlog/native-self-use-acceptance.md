# macOS 自用原生验收

[返回 Backlog](./README.md) · [自用需求](../requirements/developer-self-use.md)

状态：in-progress。优先级：P0。先验证当前基线，[v3 迁移](./wails-v3-migration.md) 与 [插件小窗](./plugin-windows-and-sessions.md) 完成后重复关键场景。目标是把已知修复和新能力转为当前开发机实际可用的行为。

## 验收环境

记录 macOS 版本、CPU 架构、应用提交、插件版本与 revision。测试先使用独立数据与缓存目录，不操作唯一自用安装和真实凭据。没有对应硬件或外部服务条件的场景注明未验证范围，不伪造结果。

## 当前自用清单

- [ ] 原生应用可构建、启动与退出，窗口不残留，关闭后后台请求和订阅释放。
- [ ] 快捷键呼出、冲突提示、配置恢复、隐藏与重新激活符合预期。
- [ ] 焦点恢复、中文输入法、Esc、透明窗口、拖拽、缩放和可用多屏场景通过检查。
- [ ] 文本、图片与文件剪贴板输入、清空、防抖、打开目录及保存对话框正确。
- [ ] 六个官方插件重新打包并在独立目录安装；同版本重装保留禁用状态、使用次数和存储。
- [ ] 已安装旧包不会自动得到源码修复：在有备份的测试安装更新翻译与 JSON 插件，核对 revision 和兼容行为，再记录自用安装升级步骤。
- [ ] 插件启停、损坏元数据提示、重载及 iframe 稳定性通过原生操作验证。
- [ ] 翻译的新输入、清空、取消、旧响应与快捷键行为正确；真实网络验收在具备测试凭据时执行，模拟结果不记为真实 DeepL 验收。
- [ ] macOS 本地凭据读写和失败提示通过测试数据验证；没有系统 Keychain 接入，日志不暴露值。
- [ ] 新插件小窗独立运行，启动器隐藏后继续工作；两个实例的上下文、请求、计数和事件不串用。
- [ ] 小窗关闭重开、插件更新禁用及资源清理符合会话约定。
- [ ] 本机测试、前端构建、官方插件打包命令可重复运行，错误输出可定位；测试环境与自用数据隔离。

## 完成与延期规则

保留记录而不是只勾选清单：每项注明操作、结果、版本和证据。外部网络或额外显示器不可用时，记录适用范围与残留项；影响本机核心路径的失败必须修复。Windows、签名公证和真实更新故障演练分别由 [Windows 任务](./windows-compatibility.md) 与 [分发任务](./distribution-and-update-acceptance.md) 跟踪，不阻塞本阶段。

## 实施记录

2026-10-04 延续 Wails v3 迁移验收。环境为 macOS 26.6.2 / arm64、Wails Beta.27 / Go 1.26.8；基于 `99fb0c6`，本轮仅修复验收发现的问题。使用独立临时数据库、插件 revision、缓存和合成凭据。通过 CLI、Wails 官方 MCP 及临时 Go overlay 探针操作自己的测试应用；没有使用 computer use，没有修改正式安装或请求系统权限。

本轮修复透明背景、呼出后键盘焦点、组合输入期间 Esc，以及 macOS 快捷键共享注册无法报告冲突的问题。独立交叉审查还发现并修复退出锁反转：快捷键生命周期先进入主线程再取锁。十轮交错注册/主线程清理及四轮并发更新/菜单退出通过。具体操作、脱敏结果及探针见 [本轮证据](../reviews/evidence/2026-10-04/README.md)。

| 场景 | 实际结果与边界 |
| --- | --- |
| 构建、原生菜单与退出 | 当前架构生产 `.app` 构建/签名；真实 AppKit Refresh/Reload 后绑定恢复；Quit 正常退出且测试配置的快捷键可被另一个进程注册 |
| 快捷键冲突与回退 | 独立辅助应用独占 L，更新配置返回 Carbon -9878 并恢复原 K；释放后更新/保存/恢复通过。定向合成 Carbon 事件验证实际注册处理器和呼出/隐藏回调；物理全局按键仍待验 |
| 焦点与窗口 | 三轮辅助应用 → 启动器 → 辅助应用的真实前台 PID/keyWindow 检查通过；没有辅助应用预先让出激活。窗口/背景透明且 WebKit 不绘制背景，自己的 WebView 快照已检查 |
| 输入法 | 原生 WebKit 合成 composition/Esc 保留输入；前端回归覆盖启动器、插件页及管理页，包括 keyCode 229。真实中文输入法候选与提交需要人工复验 |
| 双屏与尺寸 | 当前 2560×1440 主屏及 1512×982 左侧屏，负坐标定位、隐藏再呼出居中、框架尺寸调整通过；没有验证手动拖拽、物理缩放和显示器热插拔 |
| 剪贴板 | 文本、PNG、文件 URL 原生读取通过；React 合成文件粘贴显示附件。备份原剪贴板全部格式到内存，测试后逐格式比对恢复；未将原值写入证据 |
| 对话框 | 真实 NSOpenPanel 附着启动器，多选/文件/不选目录配置与取消返回通过；取消不改变插件 revision。选择安装、保存和打开目录的完整流程仍待验 |
| 本地凭据 | 合成值原生绑定读写、文件 0600/目录 0700、隔离文件故障返回错误、日志无合成值与清理通过；未使用 Keychain 或真实凭据 |

既有插件安装、存储及 iframe 迁移检查见 [2026-10-03 记录](./wails-v3-migration.md)，不是本页所有清单已完成。物理快捷键/中文输入法、系统首次权限流程及上表未覆盖的操作仍待验；插件小窗另有依赖任务，不能在本轮勾选通过。
